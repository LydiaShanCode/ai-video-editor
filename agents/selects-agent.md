# Selects agent

Pull the windows inside each raw clip that are worth a shot. Write `SELECTS.md`.

## Score

For each clip, cut on scene changes. If a span is much longer than the style's average shot, slice it into windows of about that length. Keep up to three windows, spread across the clip.

Score a window from:

- Loudness in that span
- Whether the picture actually changes
- How close the length is to the style's average shot

Near-silent windows with no cut score very low and should be described as held. Quiet windows with a little sound stay available, because a script sometimes asks for stillness.

## Do not

- Drop a quiet clip just because a louder one exists. The editor makes that call with the script.
- Score the style references. They are not footage.
